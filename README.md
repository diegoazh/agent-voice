# agent-voice

Local, privacy-first text-to-speech for coding agents (Claude Code, Codex, OpenCode, Pi, Gemini CLI), powered by Kokoro. Nothing leaves your machine.

Status: design phase. See [docs/design.md](docs/design.md).

## Development

```sh
uv sync          # create .venv and install runtime + dev dependencies
uv run pytest    # run the tests
```
